# criteria.csv 열 구조

숫자 기준표(`data/criteria.csv`)의 열과 작성 규칙. 서비스는 숫자 질문에 이 표를 조회하고, 출처(규정명·조항·쪽)를 인용한다.
범위는 CLAUDE.md "기준표 범위"를 따른다. 작성 순서: 목원 → 한밭 → 한남 → 배재 → 충남.

## 형식

- UTF-8 BOM + CRLF (`eval/questions_dev.csv`와 같음). csv 모듈로 읽고 쓴다.
- 긴 형태: 한 행 = "대학·입학년도 범위·대상·이수유형·항목" 하나에 값 하나.

## 열

| 열 | 설명 |
|---|---|
| 행ID | 고유 번호 (예: MW-001) |
| 대학 | 배재 / 충남 / 한남 / 한밭 / 목원 |
| 입학년도_시작 | **원문이 정한 범위의 시작.** 원문에 하한이 없으면 비운다 |
| 입학년도_끝 | 비우면 현행까지 |
| 대상단위 | 대학 / 계열 / 단과대학 / 학과 |
| 대상 | 2026 기준 현재 이름. 대학 공통 행은 "전체" |
| 구분 | 주 / 타 (복수·부전공일 때 주전공 쪽인지 타전공 쪽인지). 해당 없으면 비움 |
| 이수유형 | 아래 코드 |
| 항목 | 아래 코드 |
| 값 | 숫자 |
| 값_최대 | 값이 범위일 때(예: 36~51) 위쪽 끝. 아니면 비움 |
| 비교 | 이상 / 이내 / 정확히 / 범위 (아래 기본값 규칙). 범위는 값~값_최대일 때(예: 자유선택 0~23) |
| 단위 | 학점 / 점 / 유닛 / 시간 / % (%는 졸업학점 대비 비율, 한밭 교양 25% 이상. 시간은 목원 비교과 20시간) |

| 항목원어 | 학교가 쓰는 이름 (예: 교필 → 공통기초교양) |
| 출처파일 | `data/raw/` 안 파일명 |
| 출처조항 | 규정명 + 조·별표 |
| 출처쪽 | `PDF 쪽(인쇄 쪽)` 형식. 인쇄 쪽이 없는 문서는 PDF 쪽만 적는다 |
| 출처등급 | A~D (`data/README.md`) |
| 기준값여부 | 기준 / 참고 |
| 상태 | 확정 / 잠정 / 확인불가 / 불가 / 없음 (불가는 아래 규칙 9, 없음은 규칙 13) |
| 확인일 | YYYY-MM-DD |
| 비고 | 값이 다른 출처, 구값, 사유 |

### 이수유형 코드
단수, 복수, 부전공, 심화단수, 심화복수, 심화부전공, 교직단수, 교직복수, 교직일반복수, 교직일반부전공, 융합과정, 마이크로디그리, 트랙

한남 2023학번~의 융합교육과정 유형(시행세칙 제20조의2 ① 4호 다목): 융합코드쉐어, 융합마이크로디그리, 융합트랙, 융합전공. 부전공·복수(다전공)는 기존 코드를 쓴다. 마이크로디그리와 트랙은 별개 제도라 합치지 않는다.

배재 2025학번~(세칙Ⅰ 제17조 ⑦ 2호): `융합과정` — "마이크로디그리, 트랙, 부전공, 다전공 중 어느 하나를 포함하여 졸업소요 최소학점을 이수"하는 방식의 묶음이다. 별지3 2025~ 표의 전공과정(주전공 60)·공유혁신과정 값은 이 묶음에 공통인 값이라 `융합과정` 행에 둔다. 묶음 자체는 학사 선택 비교의 선택지가 아니므로 조건을 `비교 제외: 묶음 공통값(선택지는 개별 유형)`으로 쓴다(규칙 10). 선택지는 개별 유형이다: 부전공, 복수(배재 용어 다전공), `마이크로디그리`, `트랙`. 배재의 마이크로디그리·트랙(학칙 제21조의9·제21조의7)은 한남의 `융합마이크로디그리`·`융합트랙`(융합교육 필수의 한 유형)과 맥락이 달라 코드를 따로 두고, 마이크로디그리와 트랙도 서로 합치지 않는다. 대학 간 연결은 `synonyms.json`에서 "유사 개념"으로만 한다.
한남과의 관계: 한남은 융합교육을 필수로 하되 코드쉐어·마이크로디그리·트랙·융합전공(+부전공·다전공) 유형별로 전공 학점이 다르다. 배재는 유형을 고르되 전공 60·공유혁신 13은 유형과 무관하게 같고, 유형별로 다른 것은 융합과정 학점(부전공 18, 다전공 36 등)뿐이다.
충남 별표 1(교육과정 해설)의 구분 이름은 연도마다 다르다. 2022~2025는 "단수전공자·복수전공자·부전공자·교직단수전공자·교직복수전공자"로 각각 `단수`·`복수`·`부전공`·`교직단수`·`교직복수`다. 2026~는 "(주)심화단수전공·(주)심화복수전공·(주)심화부전공·(주)복수전공·(주)부전공·(주)교직단수전공·(주)교직복수전공·(주)교직일반복수전공·(주)교직일반부전공"으로 각각 `심화단수`·`심화복수`·`심화부전공`·`복수`·`부전공`·`교직단수`·`교직복수`·`교직일반복수`·`교직일반부전공`이다. "(타)복수전공·(타)부전공·(타)교직복수전공" 행은 다른 학과 학생이 그 학과의 전공을 이수할 때의 학점이라 구분 `타`로 둔다.

## 규칙

1. **비교 기본값**: 졸업학점·이수학점·평점은 "이상", 수강상한은 "이내". "정확히"는 원문이 딱 맞춰야 한다고 할 때만 쓴다.
2. **범위 밖 학번은 조회 전에 막는다.** 서비스가 2022~2026학번 밖이면 표를 조회하지 않고 "확인 불가"로 답한다. 그래서 행의 입학년도는 원문 범위를 그대로 적어도 된다(한남 "2019학년도 이후" → 시작 2019). 범위 안인데 자료가 없을 때만 `상태=확인불가` 행을 둔다.
3. **값이 출처마다 다르면** 규정 원문(A)을 `기준`, 나머지를 `참고`로 행을 나누고 비고에 이유를 적는다. 서비스는 "학과 확인 필요"로 안내한다.
4. **구값은 행으로 넣지 않고** 비고에 값과 출처를 적는다(시점 함정 문항용).
5. **계열 단위 규정**은 계열 행으로 둔다. 학과가 어느 계열인지 확인하지 못했으면 `상태=잠정`.
6. 중복키 `(대학, 입학년도_시작, 입학년도_끝, 대상, 구분, 이수유형, 항목, 기준값여부, 조건)`은 유일해야 한다.
7. 충남 2026 심화 유형은 비고에 "신청 절차 확인 불가"를 적는다(학칙·학사운영규정에 없음).
8. **조회 우선순위**: 같은 항목에 대학·단과대학·학과 행이 겹치면 더 구체적인 대상(학과 > 단과대학 > 대학)을 쓴다. 대학 단위 기본 행 + 예외 행(사범대학·건축학(5년) 등)이 이 규칙을 쓴다.
9. **상태 `불가`**: 그 입학년도에는 해당 이수유형이 규정상 없다는 뜻이다(값은 비우고 비고에 조문). 자료가 없다는 `확인불가`와 구분한다. 학사 선택 비교는 학번에 해당하는 이수유형 행을 선택지로 삼고 `불가` 행은 선택지에서 뺀다(예: 한남 2023학번~ 단수전공만으로 졸업, 배재 2025학번~ 단수와 같은 방식).
10. **비교 제외**: 조건이 `비교 제외:`로 시작하는 행은 숫자 조회에는 쓰지만 학사 선택 비교의 선택지에서는 뺀다(예: 한남 2019~2022학번 부전공은 이수방법 조문(제12조 ④ 1호)의 선택지에 없음).
11. **이수유형 비움**: 졸업학점·평점·수강상한 행에서 이수유형을 비우면 모든 이수 방식에 공통인 값이다. 이수유형이 적힌 행은 그 방식으로 이수할 때만 다른 값이다(예: 충남 심화부전공 138). 조회는 이수유형이 적힌 행을 먼저 찾고, 없으면 이수유형이 빈 행을 쓴다. 교양·전공 등 나머지 항목은 이수유형별로 값이 달라질 수 있어 비우지 않는다. 수강상한처럼 한 항목에 조건별 행이 여러 개일 때(직전 학기 평점 구간, 입학년도 구간 등)는 조회 코드가 읽을 수 있게 조건 칸에 **정규화한 구간**을 `직전 학기 평점 4.00 이상 4.25 미만`처럼 같은 형식으로 쓰고, **원문 표기는 비고에** 적는다(예: "원문 표기: 4.00 이상"). 원문이 위쪽 끝을 쓰지 않아도 표의 순서상 정해지는 구간만 정규화하며, 원문에 없는 해석은 비고에 이유를 적는다.
12. **0학점 필수 항목**: 값이 0이어도 조건에 "이수 필수"가 적힌 행(예: 배재 2025학번~ 공유혁신_전공필수, 혁신교육과미래설계 P/F, BJ-032)은 남은 학점 계산에서 학점은 0으로 더하되, 필수 이수 목록에서 빼면 안 된다. 7단계 계산 코드는 조건 칸의 "이수 필수"를 읽어 이 항목을 미이수 필수로 안내한다. 조건 칸에는 반드시 "이수 필수"라는 문구 그대로 쓴다(코드가 이 문자열로 찾는다).
13. **상태 `없음`**: 규정상 그 조건이 없다는 뜻이다(값·비교는 비우고 비고에 근거 조문). 그 입학년도에 이수유형이 없다는 `불가`(규칙 9), 자료가 없다는 `확인불가`와 구분한다. 서비스는 "○○ 제○조 ①의 졸업요건에 평점 조건이 없다"고 조문을 인용해 답하고, "상관없다"고 단정하지 않는다. 계산 코드는 이 행을 미충족 조건으로 세지 않는다. 근거는 졸업요건을 나열한 조항에 해당 항목이 없다는 것이므로, 출처조항에 그 나열 조항을 적는다. 더 구체적인 대상의 `없음` 행은 대학 행을 덮어쓴다(규칙 8, 예: 목원 글로벌융합학부 비교과 MW-066이 대학 행 MW-065보다 우선).
14. **본문·부칙과 표 해설이 다를 때**: 같은 규정 안에서 조문 본문·부칙(적용례·경과조치)과 표 해설이 다르면 개정 이력이 더 새로운 본문과 부칙 적용례를 기준으로 하고, 해설에 남은 옛 문구는 규칙 4처럼 행이 아니라 비고에 쓴다(예: 목원 별표 4 2021~2024 표 해설의 "체험교과목 8학점"은 제27조 ④ 본문과 부칙 제2조로 일반학과 의무가 없어져, MW-068 비고에만 둔다).
15. **편입 행**: 항목 코드가 `편입_`으로 시작하는 행은 편입생에게만 적용된다. 입학년도는 비운다(원문에 하한이 없을 때). 학번은 서비스가 자동 변환하지 않고 사용자가 고른 값(편입 연도 − 2, 3학년 편입 기준 해석)을 쓰고, 편입 학년은 사용자가 고른다(배재 일반편입). 조건 칸에 `이수 필수`라는 문구는 쓰지 않는다(규칙 12의 코드가 입학 구분과 상관없이 이 문구로 행을 찾는다). 건축 5년제·간호 같은 기준표 범위 밖 학과의 편입 값은 행을 만들지 않고 비고에 적는다. 학사편입은 규칙화하지 않는다(제64조는 일반 편입생 규정).

## 검증

- 세부 행: 교양 + 전공 + 일반선택 = 졸업학점 자동 확인. 심화는 "이상"이라 별도 식으로 확인한다.
- 모든 행: 원문 쪽 이미지와 대조. 평가셋 관련 행은 전수 대조.
- 평가셋 숫자 문항 정답 대조는 3단계 마지막에 한다. 정답이 바뀌면 전→후를 먼저 보여 주고 승인받는다.
