# 평가

## 빈손 테스트 (`blank_test.csv`)
RAG를 만들기 전에 15문항을 세 조건으로 물어본다: ① gpt-6-luna 웹검색 끔(API) ② gpt-6-luna 웹검색 켬(API, `src/blank_test.py --web`, 문항당 검색 5회 상한) ③ ChatGPT 웹검색 켬(화면, 로그인 안 함).
- 문항마다 새 채팅에서 묻는다.
- 판정: 정답 / 부분 / 오답 / 확인불가
- 틀린 이유: 학교 혼동 / 학번 혼동 / 구버전 / 지어냄
- 웹검색 켬은 인용한 페이지도 적고, 인용일치(일치/부분/불일치/미확인)를 따로 채점한다.
- 인용일치 현황(luna 켬): 일치 7 · 부분 5 · 불일치 1 · 미확인 2. RAG 단계에서 같은 지표로 비교한다.
- 검색 도구 호출료는 usage_log 비용 열에 들어 있지 않다(토큰 비용만).
- 이 15문항은 개발용에 넣고 홀드아웃에서는 뺀다.

## 질문셋 (예정)
- `questions_dev.csv` 80%, `questions_holdout.csv` 20%
- 대학별·유형별(숫자/서술/함정/동의어)로 골고루 나눈 뒤 홀드아웃은 동결, 마지막에 한 번만 측정한다.
