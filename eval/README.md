# 평가

## 빈손 테스트 (`blank_test.csv`)
RAG를 만들기 전에 GPT(ChatGPT 화면)에 15문항을 웹검색 끔 / 켬으로 각각 물어본다.
- 문항마다 새 채팅에서 묻는다.
- 판정: 정답 / 부분 / 오답 / 확인불가
- 틀린 이유: 학교 혼동 / 학번 혼동 / 구버전 / 지어냄
- 웹검색 켬은 인용한 페이지도 적는다.
- 이 15문항은 개발용에 넣고 홀드아웃에서는 뺀다.

## 질문셋 (예정)
- `questions_dev.csv` 80%, `questions_holdout.csv` 20%
- 대학별·유형별(숫자/서술/함정/동의어)로 골고루 나눈 뒤 홀드아웃은 동결, 마지막에 한 번만 측정한다.

## 지표
답변 정확도 · 근거 인용 일치율 · 규정 혼동률(서술형) · 확인 불가 처리율 · 계산 일치 · 개설 과목 정밀도·재현율
