# 6단계 개선 실험 로그

숫자 표는 `eval/experiments.csv`, 서술(가설·변경·결과·결정)은 이 파일. 모든 실험은 **개발용 51문항만** 쓰고 홀드아웃은 열지 않는다.

## 공통 규칙 (2026-11-05 확정)
- 기준선: 동결한 `answer-v1`·`judge-v2`·k=5·필터 없음의 고치기 전 점수. 채택한 변경은 쌓아서 다음 실험의 기준선이 된다. 실험 하나에 변경 하나.
- 규칙은 틀린 문항이 있는 곳만이 아니라 **전체 청크에 같은 규칙**으로 적용한다 (dev에 맞춘 수정 금지).
- 색인을 바꾸면 새 컬렉션(`exp<번호>-…`)을 만들고 기준선 색인(`base-text-embedding-3-small`)은 유지한다. 청크 파일을 바꾸면 sha256을 기록한다.
- 이월 규칙: 질문과 top-5 청크(순서·본문)가 기준선과 같은 문항은 이전 답변·판정을 이월하고, 달라진 문항만 다시 돌린다. 이월 문항은 기준선의 사람 최종 판정을 그대로 쓴다.
- 사람 확인 범위: 다시 돌린 문항 중 "판정관 판정이 기준선의 사람 최종 판정과 다른 문항" + 자동 표시 불일치 문항. **고쳐진/새로 틀린 문항**도 기준선의 사람 최종 판정 기준으로 센다.
- 지표: 정답, 정답+부분, 빈손 15문항, 검색 적중(전부 / 정답 청크 ≥1개), 검색 혼입률(합계·대학·학번), 정답 청크 순위. 정답 청크 목록은 `eval/gold_chunks.json`.
- 점수 보고 문구(고정): **정답 19/51(사람 판정, 1회) / 답변 재실행 시 판정관 기준 19~23** (정답+부분은 29~33). 실험 후 점수도 같은 방식으로 흔들림 범위를 병기한다.

## 채택 문턱 (실험 0 결과로 확정, 실험 1 실행 전 기록 2026-11-05)

### 근거: 실험 0 (기준선 잡음)
- 검색(top-5)은 결정적: 3회 재실행 모두 51/51 같음 → 검색 지표에는 잡음이 없다.
- 판정관 잡음: 같은 답변을 두 번 판정하면 5/51문항 바뀜.
- 답변 잡음 포함(기준선·run2·run3, 판정관 기준): 12/51문항 바뀜, 정답 19/19/23(범위 4), 정답+부분 29/29/33(범위 4). temperature=0을 모델이 거부해 입력이 같아도 답변이 매번 다르다.
- 문항별 판정 변동률 p = 12/51 ≈ 0.24 (n = 다시 돌린 문항 수일 때 단일 실행 둘의 차이의 표준편차 σ(n) = √(n·p)).

### 규칙
1. **검색 실험(1a~7) 채택**: 검색 지표로 판단한다 (결정적이라 +1문항도 인정).
   - 대상 문항의 정답 청크 적중(전부 또는 ≥1개)이 늘고, 적중이 나빠진 문항 ≤ 좋아진 문항의 절반.
   - 혼입률이 목적인 실험은 해당 혼입률이 줄어야 한다.
   - 답변 점수 회귀 가드: 다시 돌린 문항의 순증(고쳐진 − 새로 틀린, 기준선 사람 판정 기준)이 −σ(n)보다 나쁘면 보류한다. 단일 실행으로 본다.
2. **답변 점수 개선 주장**(실험 8, 답변 프롬프트 v2): **3회 실행 평균**으로 비교한다. 기준선도 3회 평균(실험 0의 기준선·run2·run3, 판정관 기준 정답 19/19/23 → 평균 20.3).
   - 3회 평균끼리의 차이의 표준편차: σ₃(n) = √(n·p/3) = √(0.08·n). n=51이면 2.0.
   - **채택 문턱 = 평균 차이 ≥ 2σ₃(n)** (n=51이면 4.0문항, n=19(수치 문항만)이면 √1.52≈1.2의 2배 ≈ 2.5문항). 기준선과 같은 기준(판정관 판정)으로 센다. 사람 확인은 평균이 문턱을 넘은 뒤 판정이 바뀐 문항에 대해 한다.
   - 순증(고쳐진 − 새로 틀린, 3회 평균)도 같은 문턱을 쓴다.
3. 판정이 엇갈리면(지표끼리 반대) **보류**하고 이유를 적는다. 사람이 정한다.
4. 문턱 숫자(p=0.24, 2σ, −σ)는 관측치 하나에서 나온 값이다. 실험 중 더 나은 추정이 생기면 바꿀 수 있지만 바꾸기 전에 이 절에 변경 이력과 이유를 먼저 적는다.
