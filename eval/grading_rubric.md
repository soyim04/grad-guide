## 답변 프롬프트 규칙 (요약)
1. 근거에 답이 없으면 지어내지 않고 "확인 불가"라고 답하고 없는 내용을 한 줄로 밝힘
2. 질문 학번이 2022~2026학번 밖이면 "확인 불가", 다른 학번의 값을 그 학번 값처럼 말하지 않음
3. 근거마다 대학·적용 학번이 다를 수 있으니 질문의 대학·학번에 맞는 근거만 쓰고 섞지 않음
4. 숫자·조건마다 근거 번호 [1] 표시
5. 대학·학번이 없어 답이 갈리면 단정하지 않고 갈리는 조건을 밝히거나 되묻기
6. 질문에 대한 답만 간결하게

"확인 불가" 표현은 하나로 통일했다. 자동 표시는 그래도 변형("확인할 수 없", "확인되지", "알 수 없", "근거에 없" 등)을 모두 인식한다.

## 판정 (빈손 테스트와 같은 용어)
- 정답 / 부분 / 오답 / 확인불가. 확인불가는 확인불가 문항이 아닌데 "확인 불가"라고만 답한 경우(오답과 구분, 검색 실패의 신호).
- 채점유형 `확인불가`(4문항): 그 학번 값을 단정하지 않고 확인 불가로 답하면 정답. `되묻기`(1문항): 숫자를 단정하지 않고 되물으면 정답.
- 정답지는 `정답`·`핵심항목`·`오답신호` 컬럼. `메모` 컬럼은 판정관에게 주지 않는다.

## 채점 순서
1. 자동 표시(코드): 확인 불가 표현 여부, 핵심 숫자 누락, 오답신호 숫자 포함. 판정관 판정과 어긋나면 `사람확인_우선`에 표시
2. 판정관(LLM) 사전 채점: 판정, 틀린이유, 인용일치 (인용한 청크 본문 기준)
3. 사람 최종 판정: 51문항 전부. `최종판정`·`최종틀린이유`·`최종인용일치`·`최종검색적중`을 채움. 판정관과 다른 건수 = 일치율로 기록

## 틀린이유
빈손 분류: 학교 혼동 / 학번 혼동 / 구버전 / 지어냄. RAG 전용(사람이 추가): 검색 실패(근거 청크가 top-5에 없음) / 생성 실패(있는데 틀리게 읽음) / 표 구조 / 옛 문구 함정(M07처럼 해설을 집음). 복수는 `;`로 구분.

## 지표 정의
- **정답률**: 정답 / 문항 (정답+부분도 병기, 분수 함께). 전체 51, 빈손 15, 빈손 B09 제외 14, 대학별·유형별·채점유형별
- **확인 불가 처리율**: 채점유형 `확인불가` 4문항 중 최종 정답
- **인용일치율**: 일치 / (일치·부분·불일치·미확인). 확인 불가·되묻기 답변은 `해당없음`으로 분모에서 제외
- **답변 혼동률** = 학교·학번 혼동으로 틀린(정답 아님) 문항 수 / 51 (최종틀린이유 기준)
- **검색 혼입률** = top-5 청크 중 질문과 다른 대학 또는 다른 학번 판 청크 수 / 판정 가능한 청크 수. 합계·대학·학번을 따로 보고
  - 대학: 평가셋 대학이 `공통`이면 판정 안 함
  - 학번: 평가셋 학번이 비면 판정 안 함. 청크에 적용 학번 구간(`학번_시작`·`학번_끝`)이 없으면(규정 대부분) 학번 혼입으로 세지 않음 → 학번 혼입률은 편람·표 청크만 잡는 하한이다
- **검색 적중률**: 평가셋 `근거`의 조문이 top-5 청크에 있는 문항 / (있음+없음). 자동 후보(규정명+조항 문자열 일치)를 사람이 확인해 `최종검색적중`(Y/N/불명)으로 확정, 불명은 분모에서 뺌
- **판정관-사람 일치율**: 판정관 판정과 최종판정이 같은 문항 수 / 51
- 표본이 작아 소수점 차이는 해석하지 않는다.
