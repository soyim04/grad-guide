## 추출 방법

`data/chunks.jsonl`을 읽기만 했고, 시드는 **20261113**이다.

```python
import json, random
chunks = [json.loads(l) for l in open("data/chunks.jsonl", encoding="utf-8")]
base = [c for c in chunks if c["기본색인"]]          # 2,108개
sample = random.Random(20261113).sample(base, 25)
```

표의 번호(#)는 `sample` 순서다. 쪽_PDF는 청크가 걸쳐 있는 PDF 쪽 범위(시작, 끝)이고, 규정은 청크 메타데이터의 `쪽_PDF` 그대로다.

## 발견 사항

둘 다 동결 후라 고치지 않고 향후 과제로 둔다.

1. **서식이 별표로 분류돼 기본 색인에 들어옴 (#22).** 한밭 학사운영규정의 학적부 정정 신청서 양식(`07-0125`)이 `구분=서식`이 아니라 `별표`로 분류됐다. 한밭 규정류는 PDF 글자 추출에서 '별표'·'별지' 글자가 빠져 `( 2 ) < 2014.7.31.>`처럼 나오는데, 이런 표제를 별표 시작으로 인식하는 복원 규칙(`EXTRA_ANNEX`)의 부작용으로 보인다.
   - 같은 경우의 수(읽기만 해서 셈): 구분=별표인 기본 색인 청크 중 본문에 `신청서`·`서식`·`(서명)`·`(인)`·`귀하`·`신청인`·`동의서` 중 하나라도 있는 것이 **31개**다.
   - 한밭이 30개(학사운영규정 29개, 융합다전공 운영지침 1개)이고, 목원 1개(`10-0174`, 별표 6 출석 인정사유)는 본문에 '서식'이라는 단어만 있는 실제 표라 **오탐**이다. 따라서 서식 잔재는 **한밭 30개**다.
   - 이 수는 위 단서 목록 기준의 **하한**이다. 단서가 없는 서식은 세지 못했다.
2. **삭제 표시 청크 (#18).** '제39조 삭제'(7자)처럼 내용 없이 삭제 표시만 있는 청크가 기본 색인에 **64개** 있다. 삭제 조를 표시로 남기는 규칙(`구분=삭제`)의 결과이며, 검색 잡음이 될 수 있다.
